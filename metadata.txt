about=A QGIS front-end for the bhoonidhi-downloader library (https://github.com/geovicco-dev/bhoonidhi-downloader,
    MIT license). Log in with your Bhoonidhi credentials (never stored to disk --
    the session lives only in memory for the current QGIS session and is
    discarded on close), pick a direct-download satellite/sensor, set a date
    range and a spatial filter (manual bounding box or a drawn rectangle),
    search the archive, preview georeferenced scene quicklooks on the map,
    and download selected scenes. Each search is saved as a revisitable
    "query" for the session and cleaned up automatically when QGIS closes.
    External dependency: this plugin installs the bhoonidhi-downloader
    PyPI package into QGIS's Python the first time it runs (with your
    confirmation), since it is not bundled in the zip.
